## Required checks

- **Join:** fresh join plus repeated Join tap; exactly one participant row.
- **Refresh:** refresh restores the same durable identity and current rights.
- **Reconnect:** background/resume, lock/unlock, network loss/recovery and browser close/reopen.
- **Leader Recovery:** same leader and submission rights return; no transfer or reallocation.
- **Submission:** repeated Submit tap creates one canonical submission.
- **Approval:** one approval creates one award and one leaderboard increment.
